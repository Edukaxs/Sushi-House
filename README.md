# Basic PHP & MySQL Website 🌐🐘🍣

## About 🧠

This project was developed as part of the **Web Programming (PW)** course. Its purpose is to demonstrate the fundamentals of dynamic web development using **PHP** and **MySQL**, including multiple pages, database integration, and CRUD operations.

## Features 💻

* User registration
* User management
* Product registration
* Product listing
* MySQL database integration
* PHP backend
* Responsive interface with HTML and CSS

## Installation

1. Clone this repository.

2. Move the project folder to your XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** using the XAMPP Control Panel.

4. Open **phpMyAdmin** and create a new database.

5. Import the SQL file located in the `database/` folder.

6. If necessary, update the database credentials in `conectar.php`.

7. Open your browser and access:

```
http://localhost/PROJECT_FOLDER_NAME
```

## Database 🗄️

The SQL script required to run the project is available in the `database` folder.

## Notes

This application was designed to run in a **local development environment**. Because the database uses a local MySQL server (XAMPP), the project cannot be fully tested directly from GitHub.

To use all features, such as user registration and product management, the project must be configured locally following the installation steps above.
